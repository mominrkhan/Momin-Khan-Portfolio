# 🚀 Momin Khan - Portfolio

A modern, interactive portfolio website featuring 3D animations, smooth scroll effects, and an immersive user experience. Built with React and Three.js, this portfolio showcases my projects, work experience, and technical skills through an elegant, responsive interface with animated 3D elements and interactive components.

## ✨ Features

- 🔥 **3D Interactive Elements** - Animated astronaut model powered by React Three Fiber
- ⚡ **Smooth Animations** - Scroll-based animations and transitions using Motion
- 🎨 **Modern UI/UX** - Clean, responsive design with TailwindCSS 4
- 💌 **Contact Form** - Functional contact form integrated with EmailJS
- 🌍 **Interactive Globe** - 3D interactive globe showing location and connections
- 📱 **Fully Responsive** - Optimized for all devices and screen sizes
- 🚀 **Fast Performance** - Built with Vite for lightning-fast development and builds

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. **Clone the Repository**
```bash
git clone https://github.com/mominrkhan/Momin-Khan-Portfolio.git
cd Momin-Khan-Portfolio
```

2. **Install Dependencies**
```bash
npm install
```

3. **Run the Development Server**
```bash
npm run dev
```

The app will be available at `http://localhost:5173`.

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
